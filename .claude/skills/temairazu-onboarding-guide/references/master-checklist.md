# 手間いらず乗換導入 標準作業フロー（マスターチェックリスト）

乗換導入（他サイトコントローラー→手間いらず）の標準的な全作業。元データ: 導入手順書Excel「導入前作業」「導入当日作業」シート。
個別案件の手順書を作るときは、ここから **その案件に該当するステップだけを抜き出し**、施設の連携サイト・PMS有無に合わせて具体化する。

## ステップの取捨選択ルール

- **PMS連携なし** の案件 → 導入前15・16、当日16・20・22・23(PMS部分)を除外
- **Booking.com/Expedia/Agodaを使わない** → 当日6/7/8のうち該当しないものを除外
- **ANA・Trip.com系を使わない** → 当日9を除外
- **じゃらん・一休.comを使わない** → 当日12を除外
- **事前接続「可」のサイトがない** → 導入前12・13・16・17を除外（すべて当日に実施）
- **新規導入（乗換でない）** → 売止・前サイコン解約関連（導入前5、当日1）は不要。ただしこの手順書は乗換前提のため、新規の場合はその旨を明記する
- **売止（当日1〜5）の対象範囲**: 元資料には対象サイトの限定は明記されていない。基本は前サイトコントローラーで販売中の全サイトを対象とし、事前接続済みサイトの扱いなど判断に迷う場合は断定せず「⚠ 要確認」として手順書に残す
