# 名刺一覧（32名） イベント御礼メール 下書き作成ツール（GAS）

「名刺一覧」シートの名刺データを差し込み、**Gmail に下書き（Draft）を作成**する
Google Apps Script です。※送信はしません。

- **テンプレートは複数パターン管理**（「テンプレート設定」シートに行で追加、既定4種）
- **担当者（行）ごとにどのテンプレートを送るか選択**（「名刺一覧」シートのF列プルダウン）
- **CC**: `biz@temairazu.com` を**全件・全テンプレート共通で自動付与**（`CONFIG.CC`）
- **差出人**: 手間いらず株式会社 徳原（`CONFIG.SENDER`）
- **氏名の差し込み**: 「姓 名」形式（例：塚本 勝）から **苗字のみ** を抽出（例：塚本 様）
- **メールアドレス空欄・テンプレート未選択の行**: スキップして実行後のログに一覧表示

## 使い方

1. 元の Excel（`名刺一覧`シート、32名）を Google スプレッドシートとして開く。
   - シート名は `名刺一覧` のままでOK（1行目=タイトル、3行目=見出し、4行目からデータ）。
2. 拡張機能 → Apps Script を開き、`コード.gs` の中身を貼り付けて保存。
3. スプレッドシートを再読み込み → メニュー **「イベント御礼メール」** が表示される。
4. メニュー **③ テンプレート・選択列を準備** を実行
   → 「**テンプレート設定**」シート（4行の例入り）と、`名刺一覧`シートの**F列にプルダウン**が自動でできる。
5. 「テンプレート設定」シートで、各行に **テンプレート名・件名・本文** を書く。
   - 行を増やせば5個目以降のテンプレートも追加できます。
   - 差し込みタグ: `{{会社名}}` `{{苗字}}`（署名・CCは自動付与、本文には書かないでください）
6. 「名刺一覧」シートの各行（担当者）で、**F列「テンプレート」から送るテンプレートを選ぶ**。
7. **① プレビュー（下書きは作らない）** で、誰にどのテンプレートが使われるか確認。
8. 問題なければ **② Gmail下書きを作成** → Gmailの「下書き」で最終確認して送信。

## テンプレート設定シートのレイアウト

| 列 | 内容 |
|----|------|
| A | テンプレート名（例：新規／既存／お礼のみ／汎用。名刺一覧のプルダウンに使われる） |
| B | 件名 |
| C | 本文（`{{会社名}}` `{{苗字}}` が使えます） |

## 名刺一覧シートの列マッピング

| 列 | 内容 |
|----|------|
| B | 会社・施設名 |
| C | 氏名（姓 名） ※ここから苗字だけ抽出 |
| D | 役職（未使用） |
| E | メールアドレス |
| F | テンプレート（プルダウン。「テンプレート設定」シートのA列から選ぶ） |

## 検証結果

差し込み・CC付与・テンプレート振り分けロジックをシミュレーションで確認済み：
- メールアドレスありでテンプレート選択済みの行 → 正しく件名・本文・CC(`biz@temairazu.com`)が付与される
- メールアドレス空欄の行 → スキップ
- テンプレート未選択、または「テンプレート設定」シートに存在しない名前を選んだ行 → スキップ（ログに一覧表示）
