# 名刺一覧（32名） イベント御礼メール 下書き作成ツール（GAS）

「名刺一覧」シートの名刺データを差し込み、**Gmail に下書き（Draft）を作成**する
Google Apps Script です。※送信はしません。

- **件名・本文はスプレッドシート上で直接書きます**（コードを触る必要はありません）
- **差出人**: 手間いらず株式会社 徳原（`CONFIG.SENDER`）
- **CC**: `biz@temairazu.com` を全件に付与
- **氏名の差し込み**: 「姓 名」形式（例：塚本 勝）から **苗字のみ** を抽出（例：塚本 様）
- **メールアドレス空欄の行**: スキップして実行後のログに一覧表示

## 使い方

1. 元の Excel（`名刺一覧`シート、32名）を Google スプレッドシートとして開く。
   - シート名は `名刺一覧` のままでOK（1行目=タイトル、3行目=見出し、4行目からデータ）。
2. 拡張機能 → Apps Script を開き、`コード.gs` の中身を貼り付けて保存。
3. スプレッドシートを再読み込み → メニュー **「イベント御礼メール」** が表示される。
4. メニュー **④ 件名・本文シートを準備** を実行
   → **「件名・本文設定」シート**が自動で作成される。
5. その「件名・本文設定」シートを開き、
   - **B1** に件名
   - **B3** に本文（セル内で `Alt+Enter`（Windows）/ `Option+Enter`（Mac）で改行）
   を自由に書く。差し込みタグは `{{会社名}}` `{{苗字}}` が使えます。
   **署名は自動で末尾に付くので、本文には書かないでください。**
6. **① プレビュー（下書きは作らない）** で差し込み結果を確認。
7. 問題なければ **② Gmail下書きを作成** → Gmailの「下書き」で最終確認して送信。

## 差し込みタグ

| タグ | 内容 |
|------|------|
| `{{会社名}}` | 会社・施設名（B列） |
| `{{苗字}}` | 氏名（C列「姓 名」）から抽出した苗字のみ |
| （自動） | 署名（`CONFIG.SENDER`）が本文の末尾に自動追加されます |

## 列マッピング（`名刺一覧`シート）

| 列 | 内容 |
|----|------|
| B | 会社・施設名 |
| C | 氏名（姓 名） ※ここから苗字だけ抽出 |
| D | 役職（未使用） |
| E | メールアドレス |

## 検証結果

全 **32件**が下書き対象（メールアドレス空欄なし、スキップ0件）。全件で
「姓 名」形式から苗字を正しく抽出できることを確認済みです
（例：波多野 真季亜 → 波多野 様）。件名・本文をシート側のセルから読み込み、
差し込み・署名付与まで正しく動作することも確認済みです。
