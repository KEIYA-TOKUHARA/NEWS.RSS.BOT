# 出張訪問 お礼メール 下書き作成ツール（GAS）

宮崎・鹿児島出張の訪問先（Eight名刺CSV）へのお礼メールを差し込み生成し、
**Gmail に下書き（Draft）を作成**する Google Apps Script です。送信はしません。

- **差出人**: 手間いらず株式会社 徳原（`CONFIG.SENDER`）
- **件名**: `ご訪問御礼（手間いらず株式会社 徳原）`
- **CC**: `biz@temairazu.com` を全件に付与
- **テンプレ4種**（AH列「区分」で行ごとに選択）
  - `新規` … TEMAIRAZU紹介＋オンライン説明の打診あり
  - `既存` … 日頃の御礼＋サポート姿勢（打診なし）
  - `お礼のみ` … アポ打診の雰囲気を出さない純粋な御礼
  - 空欄 … 汎用（軽くご説明の機会に触れる）
- **挨拶（昨日／先日）**: AI列「挨拶」で手動指定が最優先。空欄なら名刺交換日（O列）から
  自動判定（実行日の前日=昨日、それ以前=先日）。名刺交換日が正しくない行は手動で上書き。
- **除外**: AJ列に `除外` と入れた行は対象外
- **メールアドレス空欄の行**: スキップして実行後のログに一覧表示

## 使い方

1. EightのCSVをGoogleスプレッドシートにインポート（1行目=見出し、2行目〜=データ）
2. 拡張機能 → Apps Script に `コード.gs` を貼り付けて保存、シートを再読み込み
3. メニュー **お礼メール → ③ 作業列を準備** … 区分/挨拶/除外のプルダウン列（AH〜AJ）を自動作成
4. シート上でデータを修正・入力
   - 瀧澤様の会社名 → **メインホテル** に修正（Eightの読み取りミスで人名が入っている）
   - 豊永様の会社名 → **旅行人山荘**（と思われる）を補完
   - 各行の「区分」を選択（新規／既存／お礼のみ、空欄=汎用）
   - 名刺交換日が怪しい行は「挨拶」を手動選択
5. **① プレビュー** で宛先・テンプレ・挨拶の振り分けを確認
6. **② Gmail下書きを作成** → Gmailの「下書き」で最終確認して送信

## 列マッピング（Eight CSV）

| 列 | 内容 |
|----|------|
| A | 会社名 |
| D / E | 姓 / 名 |
| F | e-mail |
| O | 名刺交換日 |
| AH | 区分（作業列・プルダウン） |
| AI | 挨拶（作業列・プルダウン） |
| AJ | 除外（作業列・プルダウン） |
